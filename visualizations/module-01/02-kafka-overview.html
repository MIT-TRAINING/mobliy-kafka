Kafka overview & use cases

Apache Kafka is a distributed event streaming platform: it lets many systems publish streams of records, stores them durably and in order, and lets many other systems read them — in real time or later.

01 Publish & subscribe

Producers write events to topics; any number of consumer groups read them independently.

02 Store durably

Events are written to disk and replicated across brokers, kept for a configured retention period.

03 Process in order

Order is guaranteed within a partition, so related events (same key) are processed in sequence.

04 Scale horizontally

Topics are split into partitions spread over brokers — add brokers and partitions to add throughput.

Use-case explorer

Pick a pattern to see how data flows through Kafka. The same cluster usually serves many of these at once.

A useful mental model: Kafka is the central nervous system of a data platform. Instead of N×M point-to-point integrations, each system connects once to Kafka — producers don't need to know who consumes, and new consumers can be added without touching producers.
