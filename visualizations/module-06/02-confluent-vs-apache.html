Topic 2

Confluent vs Apache Kafka: features & licensing

"Confluent" is not one licence. Its features fall into three tiers: Apache 2.0 (Kafka itself), the Confluent Community License (free to use, with one restriction) and the Confluent Enterprise licence (paid). Click the features your platform needs, or load a preset. The verdict shows the licence you need and the Apache alternative for each paid feature. Then tick We will sell Kafka as a hosted service and see what changes.

Confluent CommunitySchema Registry, ksqlDB, REST Proxy, many connectors (JDBC, Elasticsearch, HDFS…)Use in production for free, read and modify the source codeYou may not offer the software itself as a competing SaaS (the licence's "excluded purpose")
Confluent EnterpriseConfluent Server features (RBAC/MDS, Cluster Linking, Self-Balancing Clusters, Tiered Storage, audit logs, schema validation), Control Center, Replicator, commercial connectorsUse under a paid subscription that includes supportPaid. A 30-day trial starts at install, and a free developer licence covers a single-broker cluster
Admin takeaway: run cp-server only if you plan to license it. On a cluster without a licence, use cp-kafka (plain Apache Kafka) for the brokers and keep the Community components on top. Then no feature silently stops working when the trial ends. On Confluent Cloud there is no licence file: you pay for usage, and some features are available only on certain cluster types (Topic 3).
Licensing trap: the 30-day trial licence starts the first time Confluent Server runs without a licence key. If you install the lab or a proof of concept long before go-live, the Enterprise features may stop working right in the middle of it. Check confluent.license and the broker logs for licence warnings before any demo.
