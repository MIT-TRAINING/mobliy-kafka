Confluent CLI overview & authentication

One binary, confluent, manages both Confluent Cloud and Confluent Platform. Before most commands work, it needs a context: who you are, and which environment and cluster you mean. Commands are run as learner l07. Try topic list first, then build the context step by step and watch the chain light up. Notice that produce needs one more thing on Cloud: an API key.

Two kinds of credentials

Your login (control plane)

confluent login gets a short-lived token for you. The CLI uses it for management calls over HTTPS: environments, clusters, service accounts, role bindings, and topic create / list / describe / delete through the Kafka REST API.

Cloud
confluent login [--save] [--organization …]. Email and password or SSO
Platform
confluent login --url https://mds:8090 --certificate-authority-path ca.pem. LDAP username and password
CI / scripts
CONFLUENT_CLOUD_EMAIL / CONFLUENT_CLOUD_PASSWORD, or CONFLUENT_PLATFORM_USERNAME / _PASSWORD / _MDS_URL

API key (data plane, Cloud)

Producing and consuming use the Kafka protocol on port 9092. Every Kafka client authenticates with an API key and secret (SASL/PLAIN over TLS) that belong to a user or a service account. Your login token is not used for this.

Create
confluent api-key create --resource lkc-…. The secret is shown once
Select
confluent api-key use <key>, or pass --api-key / --api-secret
Java clients
The same key goes into sasl.jaas.config (Module 7)

Admin takeaway: before any change, run confluent context list (or confluent environment list and confluent kafka cluster list) and check the * marker. The CLI remembers the last environment and cluster you used. A topic delete typed in the wrong context deletes the topic in the wrong place.
Security gotcha: confluent login --save stores your credentials in ~/.confluent/config.json (and in the macOS keychain where available). An API secret pasted into a shell stays in ~/.bash_history. On the shared lab VMs, run confluent logout at the end of the day, and don't commit config files with keys to git.
