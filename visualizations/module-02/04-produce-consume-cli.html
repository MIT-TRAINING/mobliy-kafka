kafka-consumer-groups.sh --describe

Only named groups (non-blank --group) can be described — ephemeral console-consumer groups disappear once you stop them.
Try this: start a consumer with no --group and no --from-beginning after sending a few records — it reads nothing until you send new ones. Then start one with --group order-svc and --from-beginning, stop it, send more records, and start it again with the same group but without --from-beginning: it resumes exactly where it left off.
