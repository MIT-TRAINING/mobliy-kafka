System requirements & installation options

Every Kafka node today runs in KRaft mode (Kafka 3.3+, mandatory since 4.0 — see Module 1, Topic 6): there is no ZooKeeper to install. What changes between environments is how many nodes you run and whether the controller and broker roles share a process. Pick a topology to see the exact commands.

Java 21Kafka runs on the JVM
16 GB RAMrecommended for a multi-broker dev cluster
Docker Desktopfastest path to a local cluster
Ports 9092 / 9093client and controller listeners
Every node needs a role (process.roles=broker, controller, or both) and every node needs to agree on the controller quorum via controller.quorum.voters=id@host:port,.... That list is what replaces ZooKeeper's ensemble configuration.
Why an odd number of controllers? The metadata quorum uses Raft, which needs a majority to elect a leader and commit metadata changes. 3 controllers tolerate 1 failure; 5 tolerate 2. An even number (e.g. 2 or 4) wastes a node without buying extra fault tolerance.

Binary vs. Docker

Linux binary (tar.gz)

Extract the release, edit server.properties, format storage, start the process directly. Full control over JVM flags, disks and systemd units — the normal path for production hosts.

Docker / Docker Compose

Pull an image, pass config as environment variables. Fastest way to stand up a multi-broker cluster on a laptop, and what this course's hands-on labs use.
